# Een website die als app werkt (PWA), geen appwinkel-app

De app wordt een website die op het beginscherm geïnstalleerd kan worden en zonder internet werkt (een Progressive Web App). Het is de enige vorm die gratis is, op iPhone, iPad, Android en laptop werkt, later met een link te delen is, en de tekstherkenning uit ADR-0002 in de browser kan draaien. Een echte iPhone-app kost €99 per jaar (of elke 7 dagen opnieuw installeren); een Android-app werkt alleen op Android. Het eerste apparaat is een Samsung Galaxy S22 (Android, Chrome), waarop de leerling fotografeert en oefent.

## Consequences

- De app vraagt de browser om blijvende opslag en biedt een exportknop voor een back-up van de voortgang.
- Moet de app later ook op iPhones werken, bijvoorbeeld bij delen met andere gezinnen: Safari kan gegevens wissen van een website die een tijd niet gebruikt wordt, tenzij die op het beginscherm staat. Op iPhone moet de app dus op het beginscherm geïnstalleerd worden.
