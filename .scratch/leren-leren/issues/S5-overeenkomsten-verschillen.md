# S5: Overeenkomsten en verschillen

**What to build:** Een paar leeritems dat de leerling door elkaar haalde, of dat sterk op elkaar lijkt, komt samen terug zodat hij het verschil leert zien. Zie beslissing 2 in `../beslissingen.md`.

**Blocked by:** S1

**Status:** ready-for-agent (gebouwd; wacht op controle op de S22)

- [x] Verwarring herkennen: een fout antwoord dat bij een ander woord hoort, of een tik op een andere plek
- [x] Een verwarring blijft terugkomen tot beide daarna zonder hulp goed gingen
- [x] Zonder verwarring: een paar dat op elkaar lijkt (spelling of plekken vlak bij elkaar), niet binnen 7 dagen opnieuw
- [x] Hooguit één paar per sessie, direct na elkaar aan het eind, niet bij een vrijwillige extra
- [x] Meldingen: "Je haalde … en … door elkaar", "En nu … Wat is anders?", daarna beide naast elkaar
- [x] Een teruggezet leeritem komt nooit tussen de twee van het paar
- [x] Tests
